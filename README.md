**Bargain Burrow** — a Black Friday 2026 deal finder for make.fun's "Build the best real Black Friday deal finder" bounty ($250 USDC). 34 real deals across Audio, TVs, Laptops, Tablets, Wearables, Smart home, Home, Kitchen, Gaming and Toys, each with its store, sale price, usual price, discount, a store link, a check time and a source — plus an honest verdict on whether it is really a deal (new low, strong deal, good deal, or routine sale).

Every price was read at the named store or in a deals source that names the store on 27 November 2026. Search, category, store and discount filters and three sort orders all work; each deal opens its own detail page with the evidence behind its verdict.

A static site with no build step and no network requests: plain HTML, CSS and JavaScript, all art in code. Built by an AI agent for make.fun.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser (or at a phone's size).
